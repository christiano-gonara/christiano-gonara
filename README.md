## Projetos em destaque

### [Análise de dados do setor de alimentação — Abrasel](https://github.com/christiano-gonara/teste-abrasel-dados)
Projeto de análise de dados abertos de CNPJ, com pipeline de tratamento, notebook reproduzível e dashboard executivo.
**Python · Jupyter · DuckDB · Parquet**

### [Padrinho Track](https://github.com/christiano-gonara/padrinho-track)
Sistema web interno para acompanhar o programa de mentoria acadêmica: presenças, reuniões, advertências, relatórios e certificados.
**Python · Flask · SQLite/PostgreSQL · pytest**

### [Candidatos TSE](https://github.com/christiano-gonara/candidatosTSE)
Aplicação web para consultar candidaturas de Minas Gerais usando dados eleitorais do TSE, com busca por nome ou número e filtros por cargo e partido.
**Java · Spring Boot · Thymeleaf · OpenCSV**

### [Web Scraper com Scrapy](https://github.com/christiano-gonara/web-scraper-scrapy)
Crawler para coleta e filtragem de dados de e-commerce, com paginação e exportação estruturada em JSON.
**Python · Scrapy**

### [PCP Lite](https://github.com/christiano-gonara/pcp-lite)
Projeto em equipe de dashboard industrial com módulos estratégico, tático e operacional e integração com REST API.
**JavaScript · Bootstrap · Chart.js**

### [Hotel Descanso Garantido](https://github.com/christiano-gonara/hotel-descanso-garantido)
Sistema de gestão hoteleira com cadastro de clientes, quartos e estadias, persistência em arquivos binários e testes automatizados.
**C · Munit**
